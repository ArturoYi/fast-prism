这个仓库可以放多个 SDK。构建脚本使用 Gradle Kotlin DSL。通用的 Android、lint 和 Maven 发布配置在 `build-logic` convention 里。

## 仓库里有什么

- `fast-dowload/` 是 FastDowload 这一个 SDK。
- `:fast-dowload:core` 与 `:fast-dowload:engine` 是它的纯 JVM 子模块，不依赖 Android。
- `:fast-dowload:testing` 提供 MockWebServer 夹具，不发布。
- `:fast-dowload:sample` 是这个 SDK 的 Demo，只给本机运行。文件写到应用内部目录，只声明网络权限。
- `build-logic` 是构建插件，不是业务 SDK。

下载器子模块这一阶段还没有接上发布插件。以后可发布库自己声明 `group` 和 `version`。对外类型用 `api`，内部依赖用 `implementation`。模块之间写 `project(":其他模块")`，不要写死版本。

## 本地命令

在仓库根目录执行：

```bash
./gradlew ciCheck
./gradlew :fast-dowload:core:test :fast-dowload:engine:test
./gradlew :fast-dowload:sample:assembleDebug
```

文档站在 `docs/`：

```bash
cd docs
npm install
npm run dev
```

浏览器打开 `http://localhost:3000`。
