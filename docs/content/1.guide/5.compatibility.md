下面每一项都有结论。数字以仓库里的 `gradle/libs.versions.toml` 为准。

| 项 | 结论 |
| --- | --- |
| minSdk | **26**。更低的系统不在支持范围内。 |
| targetSdk | **36**。示例应用使用这个目标。可选的 `fast-download-notify` 使用 `dataSync` 前台服务。Android 12 及以后如果系统拒绝启动前台服务，会改走 WorkManager。 |
| compileSdk | **36**。 |
| 语言 | Kotlin。公开接口可以从 Java 调用，入口是 `FastDownloader`、`DownloaderConfig.Builder` 和 `DownloadRequestBuilder`。编译用 JDK 17，打进 AAR 和 JAR 的字节码是 11，并打开 core library desugaring。 |
| OkHttp | 可选。坐标 `io.github.ArturoYi:fast-download-okhttp`。不引入时用 `HttpURLConnection`。 |
| Cronet | 可选。`CronetHttpClient` 只依赖 `cronet-api`。应用自己提供 `CronetEngine`，这个 SDK 不附带原生库。 |
| RxJava | 可选，RxJava 3。协程仍然在 `fast-download-ktx`。 |
| Room | 任务库在 `fast-download-android`。schema 变更要加 Migration，并带迁移测试。 |
| 通知和前台服务 | 可选，在 `fast-download-notify`。不依赖时不合并 `POST_NOTIFICATIONS`、`FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_DATA_SYNC`，也不带入 WorkManager 的 `WAKE_LOCK` 和 `RECEIVE_BOOT_COMPLETED`。`fast-download-android` 声明 `ACCESS_NETWORK_STATE`。 |
| R8 / 混淆 | 库自身的 release 不混淆。convention 按 `namespace` 生成 consumer rules，宿主开启 R8 时保留公开 API。各模块自己的 `consumer-rules.pro` 会一并打进 AAR，用来保留 Room、前台服务和 Worker。**不按类名反射加载实现**。没有注册的客户端会打一条警告，然后用 `HttpURLConnection`。 |
| 分区存储 | 默认只写应用内部目录。调用方也可以传入自己打开的内容 Uri。不申请所有文件访问，也不写公共下载目录。 |
| 多进程 | **不做**。任务库、命令线程和保活计数都在创建下载器的那个进程里。不要在两个进程里打开同一个命名空间。 |
| 进程被杀 | 前台服务和 WorkManager 只在进程还活着时有用。进程被杀掉后，下次启动从断点继续，不会自动拉起。 |

`public_id`、`ErrorCode.code` 和 `Status.value` 从 0.1.0 起不改值。1.0.0-rc 只增加可替换接口和可选模块，不改这些已经发布的签名。
