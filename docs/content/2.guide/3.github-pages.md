文档站是 [Docus](https://docus.dev/en) 项目，位于仓库的 `docs/`。它和 Android 模块分开构建。

## 在本地预览

```bash
cd docs
npm install
npm run dev
```

打开 `http://localhost:3000`。生成静态文件：

```bash
npm run generate
```

输出在 `docs/.output/public`。

## 部署到 GitHub Pages

`.github/workflows/docs.yml` 在 `main` 上 `docs/` 有变更时生成站点，并用 GitHub Actions 部署。仓库需要先打开 Pages：

1. 打开仓库的 Settings → Pages。
2. Source 选择 GitHub Actions。
3. 推送到 `main`，或手动运行 Docs workflow。

项目页的地址是 `https://<owner>.github.io/<仓库名>/`。workflow 会把 `NUXT_APP_BASE_URL` 设为 `/<仓库名>/`。如果仓库名是 `<owner>.github.io`，base URL 则是 `/`。

文档变更不会触发 Maven 发布。
