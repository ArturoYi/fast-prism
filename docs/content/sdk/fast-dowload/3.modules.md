`:fast-dowload` 本身只聚合 `check`，不发布。下面这些子模块才是这个 SDK 的内容。

## core

纯 JVM。放请求、分块、状态、错误码，以及 HTTP 与写出目标的契约。应用 `sdk.jvm.library`，不能应用 Android 插件。`check` 会跑 `assertJvmOnly`，编译 classpath 里不能出现 Android 构件。

## engine

纯 JVM。负责下载、命令队列和断点。默认 HTTP 客户端是 `HttpURLConnection`；不注册别的客户端时会记一条警告。OkHttp 的类型不出现在公开签名里，调用方不需要为了编译引擎去依赖 OkHttp。

## android

Android 库。提供 Room 存储、网络状态，以及内容 Uri 写入。它依赖 engine。清单里只有 `ACCESS_NETWORK_STATE`。

## api

Android 库，是对外门面。`FastDownloader` 把任务、分组和查询分开，回调在主线程，同时提供 Kotlin DSL 和 Java Builder。依赖 android。默认保活是进程内计数。

## notify

可选 Android 库。提供通知、dataSync 前台服务，以及前台服务不可用时的 WorkManager 退路。依赖 api。不依赖它时，这些权限和组件不会合并进应用。在 `DownloaderConfig.Builder` 上调用 `foregroundService()`。

## okhttp

纯 JVM。显式注册的 OkHttp 客户端。在 `DownloaderConfig.Builder` 里交给 `httpClient`，用来换掉默认的 `HttpURLConnection`。

## cronet

Android 库。只编译 Cronet 的官方接口，不附带原生引擎。引擎由接入方提供，例如 Play 服务里的 Cronet，或 `cronet-embedded`。这里只接收已经建好的 `CronetEngine`。

## ktx

Android 库。在 api 之上提供协程 `await` 和进度 Flow。

## rx

Android 库。用 RxJava 3 订阅下载。`awaitSingle`、`progressFlowable` 这一类方法和协程里的挂起函数、Flow 对应。取消订阅会取消还在进行的等待。

## 不发布的目录

这些目录只服务这个 SDK 自己的开发，不进 BOM：

| 目录 | 用途 |
| --- | --- |
| `testing` | MockWebServer 夹具 |
| `sample` | Demo：一个按钮、进度条和已保存任务列表 |
