版本对齐走 BOM。再按需要引用子模块，不用自己对齐版本。

```kotlin
dependencies {
    implementation(platform("io.github.ArturoYi:fast-download-bom:1.0.0-rc"))
    implementation("io.github.ArturoYi:fast-download-api")
}
```

BOM 坐标是 `io.github.ArturoYi:fast-download-bom:1.0.0-rc`。里面还有 `fast-download-core`、`fast-download-engine`、`fast-download-android`、`fast-download-notify`、`fast-download-okhttp`、`fast-download-cronet`、`fast-download-ktx` 和 `fast-download-rx`。

前台保活另加 `fast-download-notify`。不加时继续进程内下载，清单里没有 `POST_NOTIFICATIONS`、`FOREGROUND_SERVICE` 和 `FOREGROUND_SERVICE_DATA_SYNC`。

对外类型用 `api`，内部依赖用 `implementation`。模块之间写 `project(":其他模块")`，不要写死版本。
