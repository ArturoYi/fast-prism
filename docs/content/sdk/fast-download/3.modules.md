`:fast-download` 本身只聚合 `check`，不发布。下面这些子模块才是这个 SDK 的内容。

## core

纯 JVM。放请求、分块、状态、错误码，以及 HTTP 与写出目标的契约。应用 `sdk.jvm.library`，不能应用 Android 插件。`check` 会跑 `assertJvmOnly`，编译 classpath 里不能出现 Android 构件。

## engine

纯 JVM。负责下载、命令队列和断点。`OkHttpHttpClient` 也在这里，包名 `com.arturoyi.fastdownload.okhttp`。门面未注册客户端时使用 `HttpURLConnection`，并记一条警告。OkHttp 的类型不出现在公开签名里。

## android

Android 库。提供 Room 存储、网络状态，以及内容 Uri 写入。它依赖 engine。清单里只有 `ACCESS_NETWORK_STATE`。

## api

Android 库，是对外门面。`FastDownloader` 把任务、分组和查询分开，回调在主线程，同时提供 Kotlin DSL、Java Builder、协程 `await` 和进度 Flow。协程扩展的包名是 `com.arturoyi.fastdownload.ktx`。依赖 android。默认保活是进程内计数。

## notify

可选 Android 库。提供通知、dataSync 前台服务，以及前台服务不可用时的 WorkManager 退路。依赖 api。不依赖它时，这些权限和组件不会合并进应用。在 `DownloaderConfig.Builder` 上调用 `foregroundService()`。

## cronet

Android 库。只编译 Cronet 的官方接口，不附带原生引擎。引擎由接入方提供，例如 Play 服务里的 Cronet，或 `cronet-embedded`。这里只接收已经建好的 `CronetEngine`。

## rx

Android 库。用 RxJava 3 订阅下载。`awaitSingle`、`progressFlowable` 这一类方法和门面里的挂起函数、Flow 对应。取消订阅会取消还在进行的等待。

## 不发布的目录

这些目录只服务这个 SDK 自己的开发，不进 BOM：

| 目录 | 用途 |
| --- | --- |
| `testing` | MockWebServer 夹具 |
| `sample` | Demo：多命名空间、分组、查询、监听、协程和 Rx |
